# RAM — Axiom‑1 Hardware‑Sequencer

RAM ist das erste Hardware‑Axiom im System:

∞ = GPU  
1 = RAM  
2 = CACHE  
4 = X4  
5 = CHDSK  
12 = ROM  

RAM liefert vier Wertigkeiten pro Zyklus:

- BLOCK  – Speichersegment
- CACHE  – Kurzzeitwert
- FLOW   – Datenfluss
- STATE  – Stabilität

RAM.module.js implementiert den Sequencer.
axiom-hardware-6.csv liefert die Hardware‑Axiome.
index.html zeigt RAM‑Zyklen + Hardware‑Axiome.
